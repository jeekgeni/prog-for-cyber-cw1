## Coursework Overview 

This repository contains my Programming for Cybersecurity Coursework 1, which I completed as part of my bEng Cybersecurity degree. 
The coursework consists of five individual Python programming tasks. Each of these tasks demonstrates different programming concepts and their application to cybersecurity. 

## Coursework Tasks 

Task 1 - Security Tool 

Git Branch: security-tool

A Python tool containing a selection of security related functions. The program uses a menu to allow the user to select and run different tools. 

Task 2 - Security Event Logger 

Git Branch: security-event-logger

A Python program designed to record and display security events. It demonstrates the use of user infirmation, authentication and event logging. 

Task 3 - IP Address Validator 

Git Branch: ip-address-validator 

A Python program that checs whether an ipv4 address is valid. It checks the format of the address and ensures that each section contains a number between 0-255.

Task 4 - Security Incident Manager 

Git Branch: security-incident-manager

A Python program that stores and updates security incident information using dictionaries. 
It allows the user to enter incident details, uodate the risk level and idientify critical security incidents. 

Task 5 - Cyber Security Utilities 

Git Branch: cyber-security-utilities 

A colllection of Python cybersecurity utilities organised into seperate files. The program uses main menu to allow users to access the available security tools.

Each coursework task is organised into their own Git Branch as described above.
